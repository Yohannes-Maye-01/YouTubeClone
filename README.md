# 📺 YouTube Clone - Interactive Frontend

A lightweight, fully responsive single-page **YouTube Clone** built with modern HTML5, CSS3, and vanilla JavaScript. Designed for clean performance and seamless browser-based execution, this project replicates YouTube's signature dark-mode interface and interactive functionality.

## 🚀 Features

* **Collapsible Sidebar:** Toggle between expanded and compact navigation states with responsive layout adjustments.
* **Dynamic Category Chips:** Instantly filter the video grid by tech topics such as Rust, Python, Web Development, and Computer Science.
* **Real-Time Search:** Live filtering of video titles directly from the top navigation search bar.
* **Simulated Video Modal:** Click any video card to open a custom player overlay with dynamic title loading.
* **Modern Dark UI:** Faithful recreation of YouTube's dark theme using CSS variables, custom scrollbars, and scalable SVG icons.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, CSS Grid, Custom Properties / Variables)
* **Logic:** Vanilla JavaScript (ES6+)
